🛒 <h1>Giao Diện Giỏ Hàng Mua Sắm (TechStore Cart)</h1>

Giao diện giỏ hàng thương mại điện tử thực tế, cho phép tương tác trực tiếp với sản phẩm và tự động tính toán chi phí.

🚀 Live Demo: https://kunnee9.github.io/bai_3/

✨ Chức năng nổi bật:
Thêm và xóa sản phẩm khỏi giỏ hàng một cách mượt mà.
Cập nhật số lượng và tự động tính toán tổng giá tiền theo thời gian thực.
Giao diện phản hồi tốt (Responsive) trên cả thiết bị di động và máy tính.

🛠 Công nghệ sử dụng:
HTML5 (Sử dụng các thẻ Semantic)
CSS3 (Áp dụng Flexbox để dàn trang)
JavaScript (DOM Manipulation, Array Methods, Event Handling)

💡 Quá trình phát triển:
Thông qua việc xây dựng chức năng này, tôi đã nắm vững cách quản lý trạng thái dữ liệu bằng JavaScript và làm chủ các kỹ thuật tương tác trực tiếp với DOM trên trình duyệt.
